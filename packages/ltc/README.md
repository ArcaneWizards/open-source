# `@arcanewizards/ltc`

[![](https://img.shields.io/npm/v/@arcanewizards/ltc)](https://www.npmjs.com/package/@arcanewizards/ltc)

Small library that processes real-time Linear Timecode signals
using the WebAudio API.

## Installation

```sh
pnpm add @arcanewizards/ltc
```
