# `@arcanewizards/clx`

[![](https://img.shields.io/npm/v/@arcanewizards/clx)](https://www.npmjs.com/package/@arcanewizards/clx)

Typescript implementation of the [CLX spec](https://github.com/medcelerate/CLX-Spec)
for timecode information.

## Installation

```sh
pnpm add @arcanewizards/clx
```
